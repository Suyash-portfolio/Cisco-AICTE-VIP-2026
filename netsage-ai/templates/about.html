About NetSage AI

AI + Networking + Rule-Based Checking + Human Review + Responsible AI, built for Cisco Packet Tracer troubleshooting coursework.

What It Does

NetSage AI is built for the Cisco problem statement:

"Build an AI troubleshooting helper for Packet Tracer lab problems that reads symptoms and show-command output, suggests likely causes and next steps, and always requires a human to review before accepting the fix."

NetSage AI combines a diagnosis suggestion service (AI) with a deterministic Python rule checker. The AI only uses the evidence you provide — symptom, topology, and Cisco show output — and every result must be reviewed by a human.

How It Works

Step 1. User provides the network problem.
Step 2. System checks the Cisco evidence.
Step 3. AI suggests the likely cause.
Step 4. Python rule checker performs deterministic checks.
Step 5. Human reviews the result.
Step 6. Network is fixed and verified.

Technology

A simple, understandable stack for a college project:

Frontend — HTML + CSS + JavaScript
Backend — Python Flask
AI — Demo AI + optional API
Data — CSV / JSON
Charts — Chart.js

Responsible AI

NetSage AI does not automatically change network configurations. It only provides troubleshooting recommendations. A human must review every diagnosis before accepting the solution.
